Each row is one thing you can do by clicking today, including the settings calendar and the timeline Month tab. Tick it if the agent should do that from a chat instruction: the instruction becomes a tool or skill, and the agent runs it, including several in one go.

What should be an MCP edit

Graph work is the guide. The agent should change the library the way those graph edits do. Zoom, angle, opening a panel, and switching Graph / Settings / Table stay clicks. The agent does not drive the camera.

Graph — ask the agent to do these

  • Make a link — Create a new link, Draw connection from here, Save into frontmatter. One create_link call (from, to, kind, note).
  • Make an activity set — Create an activity set, Make activity set. One create_set call.
  • Change who is in a set — Remove (set member). update_set.
  • Delete an activity set — delete_set.
  • Put a set on a period — Add to timeline. pin those materials on that date.

Ask the agent for the same kind of edit outside the graph

  • Materials — Add row, Save (drawer or peek), Remove (material row), Save (facet picker), Add (class note). create_material, update_material, delete_material. Replace, the picture chooser, and Remove (picture) are attach_sketch and clear_sketch.
  • Polish and Summarize — the agent rewrites the words, then saves with those same update calls. Summarize saves the period objective. No separate polish endpoint for each box.
  • Links — Add link, Remove (link row), Unlink in the hop flyout, a hop note. create_link, update_link, delete_link.
  • Skills — Create skill, Delete a skill or activity set, Move an activity set under a skill, − on a set path. Same set tools.
  • A period — Pin. save_period with the activities for that date.
  • Calendar — class weekdays, add or remove a grade, add / rename / delete a focus, work day, or school activity, paint a range, change a range, delete one range. get_calendar then save_calendar.

Leave as clicks: Graph, Settings, Table, Clear, Cancel, Layers, Angle, the two plane buttons, Zoom, Fit, Spread, More info, Back / forward, a member name, × on a picked chip, a facet chip, the close and back buttons, Show a month, Open the period on a date, Choose the grade, export JSON.
